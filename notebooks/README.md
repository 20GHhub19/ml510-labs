# Course notebooks

Notebook assignments are provided through the course Moodle, separately from this GitHub repository.

For S4, download the provided `s4_regression` materials. If they arrive as a ZIP, extract it and copy the resulting `s4_regression` folder into this `notebooks/` folder. Copying the ZIP alone is not enough.

The first notebook must be at:

```text
notebooks/s4_regression/00_start_here.ipynb
```

Avoid an extra nested folder such as `s4_regression/s4_regression/`. Keep all six notebook files together so their navigation and documentation links work.

Follow the [S4 setup guide](../docs/s4_regression.md) for the environment, dataset, and notebook sequence. Start Jupyter from the repository root and select **Python (ML510)**.

Downloaded notebooks, local results, and instructor corrections are ignored by Git. This README is the public entry point for the folder.
